评估架构：探针定位 + Hybrid 裁决

VANE-Bench 实测表明"把视频直接丢给多模态大模型"无法可靠检测细微时空异常。 我们的方案：全帧探针扫描定位异常窗 → 像素证据充分的 detector 直判 → 证据不足的候选窗交 Claude+rubric 定向裁决。合成缺陷视频上 10 类缺陷拦截 21/22（95%）、零误报；本平台展示的是 该管线对 真实 Wan2.1/2.2 生成视频 的检测结果。

T0 ffprobe gate→ S1 全帧信号扫描（亮度/帧差/闪烁/CLIP/光流warp，GPU 秒级）→ S2 直判（黑帧/冻结/闪烁/跳帧/意外切换，转场豁免）→ S3 GroundingDINO 主体探针（出界/变形/色相漂移）→ S4 信号融合 Top-K 候选窗 → Claude 定向裁决→ S5 T10 语义对齐（rubric 先行）

VLM 裁决三原则（E7 实测）

  1. 像素证据充分的直判、不问 VLM —— 黑帧/冻结/硬切/闪烁直接给结论，快且稳定。
  2. 问 VLM 要问具体问题 —— 带 8 连续帧拼图 + 触发信号摘要 + intended prompt，问 "主体逐格是否连续""出画是否有意"，而不是"这视频有没有问题"。
  3. rubric 先行 —— 看视频前先由 judge 从 prompt 生成 3-6 条硬标准附在裁决 prompt 里， 防止被输出内容"带着走"。消融：Nova 1/5 → Claude 4/5 → Claude+rubric 5/5。

真实生成视频上的阈值再校准

直判阈值最初在 640×360 合成视频上校准（正常 warp ≤3.1、帧差底噪 <8）。 Wan 真实生成视频纹理噪声与运动幅度大得多：wan2.1 832×480 实测 warp 残差中位数即 5.3、 高运动镜头峰值 80+。为此做了三处修正：

  1. T1 跳帧改"孤立尖峰"判定：warp > max(6.0, 3×局部中位数) 且邻帧回落 —— 持续高 warp 是运动，不是跳帧；
  2. T7 变形按 motion_level 放宽（low ×1.0 / medium ×1.6 / high ×2.2）且要求持续 3 个子采样帧 —— 活体主体姿态变化会自然改变 bbox 纵横比；
  3. T3 冻结引入导演分镜先验：camera=static 且 motion=low 的镜头判冻结需 2 倍时长。

导演分镜 JSON 同时是评估输入：计划转场点豁免 T4/T1/T2，expected_subjects 作为 GroundingDINO 的开放词汇跟踪词，motion_level/camera 作为 T3/T7 先验。 生成侧元数据反哺评估侧，是这个闭环的核心设计。
